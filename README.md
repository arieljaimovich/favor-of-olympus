# Favor of Olympus

A Greek-mythology adventure and strategy game for ages 9–15.

Pick one of ten heroes, win the favor of ten gods, and spend 45 in-game days on quests, training and exploring. The Hydra attacks on day 15, the Chimera on day 30, and Eris and Typhon on day 45.

**Play:** open `index.html` in any browser, or visit the GitHub Pages site for this repo.

Everything is in one file, `index.html`, with no build step. Progress saves automatically in the browser on each device.
